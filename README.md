# machine-learning-tinkering

Learning machine learning by building things from scratch.

## Tutorials

1. [Linear regression](linear-regression/README.md): an introduction to machine learning. Model, loss and gradient descent written in pure Python, then numpy, multiple features and scikit-learn.
2. [Logistic regression](logistic-regression/README.md): from predicting numbers to predicting yes or no. Sigmoid, log loss, decision boundaries, and how to judge a classifier with precision and recall.
3. [Neural networks](neural-networks/README.md): stacking simple models into a powerful one. Neurons, layers and backpropagation from scratch, then recognising handwritten digits.
4. [ROC curve](roc-curve/README.md): judging a classifier at every threshold at once. True and false positive rates, the curve and AUC from scratch, choosing a threshold, and when to prefer precision-recall.
